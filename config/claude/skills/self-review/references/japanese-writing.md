# 日本語文のレビュー規範

この reference は self-review の日本語文章レビューに必要な規範をまとめます。評価対象は差分内の日本語を含む文章です。技術的事実の正否や、差分から確認できない情報は評価しません。

## 意味を保つ

- 主張、評価、比重、文の働きを保ちます。範囲、条件、否定、因果、時期、数値、確度も変えません。
- 原文や提供された文脈にない事実、主体、対象、理由を足しません。自然な表現に直すために曖昧さを勝手に解消しません。
- 具体的な意味のずれを示せる場合に指摘します。好みだけを理由にした書き換えは求めません。

## 7 観点

1. **全角記号**: 日本語の文章では丸括弧、感嘆符、疑問符、コロンを半角で書きます。この表記規則は一般的な Yomiyasu の表記方針より優先します。記号が担う意味や強さは保ちます。
2. **半角英数字との空白**: 半角英数字と全角文字の境界には半角スペースを入れます。コード、URL、識別子、引用、引用元の表記、機械処理が必要とする書式は、意味や形式を変えないために必要な場合はそのまま保ちます。
3. **主語と述語**: 誰が何をどうするかを確認し、主語と述語、目的語、使役の関係が合わない箇所だけを指摘します。文脈から確定できる主体や対象は補えますが、人や役割を創作せず、自然なシステム動作を人の行為に置き換えません。
4. **擬人化**: 道具や概念に意志や感情を持たせた表現を見ます。機能や状態を述べる非生物主語、慣用表現、意味が明確な技術用語は、非生物主語という理由だけでは指摘しません。
5. **比喩動詞**: 文脈に合わない AI 風の比喩動詞は、意味と評価の向きを保つ自然な表現が明らかな場合に限って指摘します。定着した慣用句、専門用語、意味を読み取れる文学的な比喩は機械的に直しません。
6. **否定対比**: A を否定して B を示す文は、A を除いても主張や比重が変わらない場合だけ冗長さを指摘します。誤解の訂正、外れた仮説、原因の比較など意味を担う否定は残します。
7. **装飾**: 意味や用途を担わない絵文字、記号、太字、区切りの重ねすぎを見ます。ラベル、値、箇条書き、表、引用、強調、文体上の記号など、読み分けや書き手の表現に必要な書式は残します。

## 用途による例外

- 技術文では、道具の働きが明確な表現、定着した用語、意味を取り違えない慣用句を保ちます。
- エッセイや小説では、読み取れる比喩、語り、文のリズムを保ちます。意味を連想できず、主語と動作が釣り合わない表現は対象です。
- 紹介文や宣伝文では、キャッチコピー、勢い、評価、感情を表す記号を機械的に削りません。半角記号の規則と両立させるときも、表現の強さや役割を保ちます。
- PR 説明では、テンプレートの見出しと順序、変更ごとの箇条書き、チェックリスト、体言止めを文体の好みで変えません。
